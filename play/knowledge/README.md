# knowledge/

General, reusable BG3 know-how for the playing agent: rules cheat sheets, controls, UI notes, and
harness tips that apply to *any* playthrough. The operator may seed it, and the agent may add to it.

Not for playthrough-specific facts (those go in `memory/`). Anything here that comes from general game
knowledge rather than this game's own UI or tools is `[wiki]` until confirmed.
