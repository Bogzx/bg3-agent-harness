# Screenshots from claude-run-2

These are the 915 screenshots the playing agent took during claude-run-2, the run that finished the game
(2026-10-09 to 2026-10-18, Claude Opus 5.5, Explorer difficulty). The agent took them through the `screenshot`
tool; zoomed crops are included.

Each folder is one session (`S001` to `S096`). Files are named by the time the screenshot reached the agent, in
UTC. Sessions with no folder took no screenshots, or their screenshots were not kept. The images were copied as
they are from the Claude Code session logs, without edits.
