## The clock line
In runner sessions every result ends with a `⏱` clock line. Until wrap-up time it shows no time left:
`⏱ 00:21 · keep playing: you'll be told when to wrap up`. Then it says `⏱ 00:33 · 3m left: WRAP UP NOW. …` by
itself. In combat the line is `⏱ 00:31 · in a fight: finish it, taking each turn the time it needs; the session
waits for the fight`, with no time in it: a fight still on at wrap-up time holds the clock, and WRAP UP comes when
the fight ends. When the line says "no story progress for N min: change approach", the runner has measured no new
journal entry, area, waypoint or level for that long. Some minutes after the session's end the server refuses game
actions; read tools keep working.
